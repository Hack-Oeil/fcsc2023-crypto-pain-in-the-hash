# FCSC 2023 Pain in the Hash

On vous demande de trouver un petit ensemble de messages dont la somme des hachés (SHA256) vaut 0.




Fichiers:
- [pain-in-the-hash.py](pain-in-the-hash.py)




Auteur : [Cryptanalyse](https://twitter.com/Cryptanalyse)


Origine : [Pain in the Hash](http://hackropole.fr/fr/challenges/crypto/fcsc2023-crypto-pain-in-the-hash/)



-----------

## Connectez vous en WEBSSH
> http://localhost

#### tentez 
> nc pain-in-the-hash.cyrhades.fr:4000

-----------

## Ou directement avec netcat
> nc localhost:4000


-----------


## Installation manuel
Vous n'utilisez pas l'application **les CTFs de Cyrhades** ? C'est dommage !
Mais voici comment installer ce CTF manuellement :

> git clone https://github.com/Hack-Oeil/fcsc2023-crypto-pain-in-the-hash.git

> cd fcsc2023-crypto-pain-in-the-hash
